# pr_750: inkling: audio input, Metal expert MoE, and tuned Apple defaults

## Summary

Adds audio input to Inkling (the small multimodal model) and speeds it up on Apple Silicon. Everything is `__APPLE__`/`COLI_METAL` guarded or opt-in; text-only Inkling and non-Apple builds unchanged.

- **Audio input (DMel):** frames embed via a small `[mel_bins*mel_vocab, D]` table + RMSNorm and *replace* `<|audio|>` placeholder embeddings; loads from a `--keep-audio` container or an `audio.safetensors` sidecar (~10 MB via HTTP range on lazy mounts). Entry points: `--audio file.dmel` CLI, 7th serve-protocol field, `"dmel"` in the oracle harness
- **Metal expert MoE:** routed-expert matmul on the Metal GPU (`COLI_METAL=1`, opt-in) for inkling
- **Three `__APPLE__` default changes** from a measured knob sweep (not a guess)

## Relevance

- **Goal a (fmt_2_m1u):** Marginal — inkling-specific, but its tuned Apple defaults touch shared `__APPLE__` build defaults that the GLM benchmark binary also sees. Worth knowing it landed before the M1 Ultra runs.
- **Goal b (fmt_4_m1u):** Not directly relevant; its follow-up [pr_757](pr_757.md) is more interesting (adds an fmt=5 branch to `moe_gemv` — a template for the fmt=4 branch).
