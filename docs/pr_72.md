# pr_72: Metal backend (Apple Silicon): experts + fused attention + full-layer GPU, token-exact

- **URL:** https://github.com/JustVugg/colibri/pull/72
- **State:** MERGED 2026-07-13 (opened 2026-07-11 by codearranger)

## Summary

The foundational PR: colibri's first GPU tier for Apple Silicon, opt-in via `make glm METAL=1` + `COLI_METAL=1`. Unified memory removes the PCIe copy tax; default build untouched (`#ifdef COLI_METAL`); every GPU path falls back to CPU per-block on any fault or unsupported shape.

What runs on the GPU:

- **Routed-expert SwiGLU**, batched per block, read zero-copy from registered RAM slabs (bindless `gpuAddress`); resident experts' block submitted before missed experts' preads so disk I/O and GPU compute overlap
- **Fused decode attention** (S<=4, covers MTP verify): full MLA layer — q/kv projections, RoPE, absorption core, o_proj — in one command buffer
- **Full-layer command buffer**: in_ln -> attention -> residual -> post_ln -> shared expert -> router (f32 matvec + sigmoid) -> exact phase-A top-K on GPU
- **Prefill**: large row-batch `matmul_qt` GEMMs route to GPU above `COLI_METAL_GEMM_MIN` (default 16 rows)

Measured (M4 Max 128 GB, warm cache ~58% hit, MTP on, greedy): 0.38-0.43 tok/s Metal vs 0.30 CPU. **Token-exact**: greedy outputs byte-identical to CPU in every configuration. `make metal-test` = 16 standalone correctness tests vs CPU references.

## Relevance

- **Goal a (fmt_2_m1u):** The backend being benchmarked. Its gates (fmt=1/2 only) are why the fmt=2 track reproduces #103 without code changes.
- **Goal b (fmt_4_m1u):** The codebase being fixed — all fmt=4 work (fixes A/B/C) extends these kernels and gates.
