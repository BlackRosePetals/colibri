## Summary

Adds `docs/METAL-M5MAX-PERF-REPORT.md` — the independent M5 Max reproduction of the rebased Metal backend (#72), and the source of the Config A-E methodology the M1 Ultra plan mirrors.

- Tuned, the rebased Metal path reaches **2.24 tok/s — ~8.5% faster than the pre-rebase branch (2.06, issue #103)**, thanks to `PIPE` (new since the old base)
- The **default** rebased config regresses to **1.25 tok/s (-39%)**: the OMP hot-team active-spin (#77) pegs the CPU while it waits on the GPU, and on Apple's shared SoC power budget that throttles the Metal kernels (attention GPU kernel 76s -> 223s for identical work)
- Fix is two complementary flags: `COLI_NO_OMP_TUNE=1` restores GPU clocks; `PIPE=1 PIPE_WORKERS=8` hides the CPU->GPU dispatch latency the passive wait introduces
- Documents the 128 GB memory ceiling: `--ram 110` safe / `120` compresses
- Token-exactness note: output is non-deterministic run-to-run under the parallel config — benign FP-reduction ordering, throughput unaffected (see also #622)
